构建、配置与排障

按需构建，统一安装，Gateway 自动治理

Edge 的目标不是让操作者手工维护一组孤立进程，而是把可选 artifact 安装到统一目录，由 Gateway 发现逻辑单元、校验配置、启动连接、监控健康并执行有界修复。

九个逻辑连接器复用六个依赖族 artifact；每个 manifest 仍拥有独立 ID、配置、状态和修复历史。

配置生效规则

  1. Gateway 读取 manifest 与用户配置，先做 schema 和必需字段校验。
  2. 校验失败时拒绝新配置，保留当前可用实例，并投影错误和 reload-needed 状态。
  3. 纯参数更新通过 `configure` 热应用；artifact、transport、driver profile 或安装内容变化触发有界 restart。
  4. WebUI 只展示状态和人工 reload/repair 操作，不保存平台 secret。
