WEBUI SURFACE

Gateway 的浏览器控制面，不是第二个后端

WebUI 是由 Gateway 挂载的静态 Vue 应用。它通过能力合同发现可用功能，通过 HTTP 发起命令，通过 SSE 查看活动状态；Session、Mission、审批、记忆和执行图的真相始终来自 Core。

页面能力地图

对话页的三层信息

层展示内容使用时机
正文时间线用户消息、关键思考、Team/Agent 层次、折叠后的 Tool/Skill 状态和最终答案日常操作与实时跟踪
业务执行图任务、团队、智能体、工具与产物的父子和依赖关系；隐藏上下文组装等内部噪声理解并行、委派与结果流向
技术活动与证据完整事件、输入输出、审批、上下文信封、Reality 引用、耗时与错误证据故障排查、审计与复现
流式原则

先追加已确认的活动，再异步补齐详情；不能等 Turn 结束后一次性重建。事件按 identity/revision 去重，断线后从最后 ACK 的 revision 续接。

加载与性能

  • 首屏只加载认证、能力合同、Session 热尾段和当前 Turn；历史消息按游标向上加载。
  • 右侧活动、Workspace、Evidence、Memory 等重数据在面板打开后才请求和订阅。
  • 命令目录、能力合同和稳定字典可在页面会话内缓存；运行态仍以 revision 更新。
  • Markdown、表格、图和结构化详情使用专门渲染器；原始 JSON 只作为显式展开的排障材料。

Session API
02
连续补充输入

运行中的消息进入 Runtime 输入队列，由 Task Router 决定合并当前 Turn、排队、分支或创建新 Task。

Runtime
03
处理审批

待审批在全局状态和当前对话中显性出现；批准范围由本次动作、本轮、本 Session 或策略范围决定。

Approval API
04
下钻证据

先看业务图和摘要；需要复现时再打开节点详情、输入输出、原始事件和 Reality 血缘。

语言、响应式与可访问性

中英文词条完全分离，由 `zh-CN.ts` 与 `en-US.ts` 提供。移动端压缩状态为图标和数字，保留 Session、审批、输入与执行进度等主路径；所有弹窗支持 Esc，图标按钮具备可读标签，图表保留列表或详情替代视图。
