数据源连接器

把外部数据变成可验证快照，而不是直接写入事实

Source Connector 只负责连接、发现、分页读取、增量窗口和事件归一化。Gateway 与 Matrix 负责 SourcePack 映射、质量校验、事实/关系/证据提交以及水位线确认。

分页与水位线不变量

  1. 数据库使用 `limit + 1` 判断下一页，不为分页执行全表 COUNT。
  2. 同一资源的增量读取串行，不同资源可以并行。
  3. 同一水位值跨页时只推进 continuation offset；最后一页提交成功后才推进字段水位。
  4. Connector 返回 `watermark_after` 候选，Gateway/Matrix 在事实提交成功后显式 ACK。
  5. 失败重试必须复用读取 identity 和幂等键，不能重复生成事实。

SourcePack 的作用

SourcePack 位于 Core，描述外部字段如何映射为 Matrix 实体、Fact 和关系，同时规定来源键、证据与质量校验。它把“能读到表”与“这些行在业务上代表什么”分开，使同一个 connector 可以服务不同领域。

source resource
  + connector profile
  + SourcePack mappings
  + snapshot / incremental plan
  → Matrix entities, facts, relations, evidence

配置与安全

  • 数据库 URL 优先通过 secret 或环境变量引用，不在 manifest 和文档中保存明文。
  • Source Connector 是只读数据入口；任何回写都应成为独立 Tool/Automation 合同并接受权限治理。
  • 资源发现结果和快照状态由 Gateway API 展示，不要求前端保存连接凭据。
