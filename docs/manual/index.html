关键边界

  1. Gateway 是唯一 EdgeHost；Edge 不自己创建 Session、Task、Memory 或 Matrix 事实。
  2. Message connector 只处理平台消息和媒体，不内置文档编辑等业务工具。
  3. Source connector 返回标准 batch 与候选 watermark；持久提交、SourcePack 映射和事实晋升属于 Core。
  4. 每个逻辑 connector 独立配置和状态，即使多个 connector 共用同一个二进制 artifact。
  5. TUI 仍在 Core；它是轻量终端 Surface，不迁入 Edge。
